A **Student Result Management System** developed using **Python, Tkinter, and Excel**. This project provides a simple graphical user interface for managing student information and academic results efficiently.

## 📌 Project Overview

The system allows users to enter and manage student details, marks, and results through an easy-to-use GUI. Student records are stored in an **Excel file**, making it simple to maintain and retrieve result data.

## ✨ Features

* Add student details
* Enter marks for different subjects
* Calculate total marks
* Calculate percentage
* Display student results
* Store data in an Excel file
* Simple and user-friendly GUI
* Search/retrieve student result information

## 🛠️ Technologies Used

* **Python**
* **Tkinter** – for GUI development
* **OpenPyXL** – for Excel file handling
* **Microsoft Excel** – for storing student records

## 🎯 Objective

The main objective of this project is to develop a simple and efficient application for managing student results while gaining practical experience in **Python GUI development, file handling, and Excel integration**.

## 🚀 How to Run

1. Install Python on your system.
2. Install the required library:

```bash
pip install openpyxl
```

3. Download or clone this repository.
4. Open the project folder in VS Code.
5. Run the Python file:

```bash
python main.py
```
